Nexus UI

Nexus UI — Roblox UI Library

Nexus UI es una biblioteca de interfaces gráficas para proyectos Roblox, desarrollada en Luau.

Características

- Ventanas personalizables.
- Pestañas para organizar funciones.
- Botones e interruptores.
- Deslizadores y menús desplegables.
- Campos de texto.
- Opciones de idioma español e inglés.
- Interfaz diseñada con un estilo visual oscuro.

Código fuente

El archivo principal es ""NexusUI.lua"" (./NexusUI.lua).

Instrucciones para asistentes de IA

Si vas a generar un script que utilice Nexus UI:

1. Lee primero el archivo "NexusUI.lua" para consultar la API real.
2. Comprueba los nombres de las funciones y sus parámetros.
3. No inventes métodos que no estén implementados.
4. Usa ejemplos compatibles con las funciones existentes.
5. Explica cualquier requisito de ejecución o compatibilidad.
